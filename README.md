# BatteryGuard — обновлённая архитектура

## Что изменено
- Удалён AccessibilityService и XML его конфигурации.
- Добавлена плитка Quick Settings для включения и выключения.
- Плавающее окно использует `TYPE_APPLICATION_OVERLAY` и не зависит от активного приложения.
- Выключение из приложения, плитки или действия уведомления останавливает сервис, убирает окно и постоянное уведомление.
- Настройки содержат показатели температуры CPU, температуры батареи, ОЗУ, времени и заряда; порядок строк меняется перетаскиванием.
- Показатели в плавающем окне выводятся вертикально.

## Разрешения
- Для плавающего OSD требуется «Показывать поверх других приложений».
- На Android 13+ требуется разрешение на уведомления для постоянной службы.
- Отдельного общего runtime-разрешения на системные показатели CPU/ОЗУ/температуры в Android нет; `BODY_SENSORS` не запрашивается.

## Источники показателей и ограничения Android
- Температура CPU: максимальное значение среди доступных thermal/hwmon датчиков, распознанных как CPU/SoC. Производитель может ограничить доступ к ним.
- Температура батареи: системное значение `BatteryManager.EXTRA_TEMPERATURE` (десятые доли градуса Цельсия).
- ОЗУ: использованная и общая память устройства через `ActivityManager.MemoryInfo`.
- Время: локальное время в формате `HH:mm`.
- Заряд: процент заряда. Дополнительный переключатель «Вольтаж и потребление» добавляет в эту же строку напряжение в В и ток в мА.

Доступность температуры CPU зависит от прошивки и производителя устройства. Если система не предоставляет значение, приложение показывает «н/д». Приложение не получает привилегий root.

## Сборка
Проект собирается командой `gradle assembleDebug` в среде с Android SDK и Gradle. В архиве нет Gradle Wrapper, поэтому CI использует установленный Gradle через GitHub Actions.


## Дополнительные настройки показателей

- Порядок строк в списке показателей меняется перетаскиванием: удерживайте значок `☰` и переместите строку. Порядок сохраняется отдельно от включённых показателей.
- Пункт «Вольтаж и потребление» не создаёт отдельную строку в окне: при включении он добавляет напряжение и измеренный ток к строке «Заряд». Ток считывается через `BATTERY_PROPERTY_CURRENT_NOW`; это ток в мА, а не мощность в ваттах.
- Предупреждение о системных датчиках свёрнуто по умолчанию при каждом открытии настроек и раскрывается нажатием на заголовок.


### Размер плавающего окна
Ширина вычисляется по размеру текста и набору включённых показателей (с резервом под максимальную длину типичных значений). Высота зависит от количества включённых строк и размера текста. После вычисления для текущей конфигурации размеры не зависят от изменяющихся значений датчиков, поэтому окно не дёргается при обновлении показаний. Изменение размера текста или состава показателей пересчитывает размеры окна.

### Последняя корректировка плавающего окна
- Иконки находятся в одинаковых фиксированных ячейках и центрируются в них; текст всех строк начинается строго по одной вертикали.
- Уменьшены высота строк и внутренние отступы, чтобы убрать лишние пустые промежутки.
- Ширина рассчитывается по наиболее длинному реалистичному примеру только среди включённых показателей. Убран чрезмерный запас под пятизначный ток и пятизначную память.
- Строки больше не пересоздаются при каждом обновлении датчиков: обновляется только текст. Это уменьшает мерцание и скачки разметки.
- При удалении задачи из списка последних приложений сервис планирует повторный запуск через AlarmManager. Системное уничтожение сервиса больше не сбрасывает пользовательский флаг включения.
- Принудительная остановка приложения пользователем через системные настройки, ограничения прошивки или отключение автозапуска всё ещё могут блокировать перезапуск — Android не позволяет приложению обходить такие запреты.

Меню «Игры и статистика», выбор приложений, Usage Access, FPS и Shizuku удалены. Приложение показывает только плавающее окно с системными показателями.
